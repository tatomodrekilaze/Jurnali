ჟურნალი

მონიშნეთ გაცდენა ერთხელ და ის ყველა მომდევნო გაკვეთილზე თავად გადავა. onlineschool-ის ჟურნალი, უფრო მარტივად.

ტელეფონზე (Android)

ჩამოტვირთვა ტელეფონზე

  1. გახსენით ჩამოტვირთული ფაილი.
  2. თუ ტელეფონი ნებართვას გკითხავთ, დააჭირეთ „ნების დართვა“.
  3. გახსენით „ჟურნალი“ და შედით ისე, როგორც ყოველთვის.
  4. ტელეფონი პაროლის დამახსოვრებას შემოგთავაზებთ. დაეთანხმეთ, და მეტჯერ აღარ მოგიწევთ შესვლა.
  5. ქვემოთ, მარჯვნივ გამოჩნდება მწვანე ღილაკი „✓ დასწრება“. დააჭირეთ.

კომპიუტერზე

გადაათრიეთ ეს ღილაკი სანიშნეების ზოლზე (Ctrl+Shift+B აჩენს ზოლს):

✓ დასწრება

შემდეგ გახსენით onlineschool, შედით და დააჭირეთ ამ სანიშნეს.

უსაფრთხოება

პაროლი არასოდეს გადის აქ: შესვლა ხდება onlineschool-ის საკუთარ გვერდზე. აპლიკაცია ინახავს მხოლოდ იმას, რასაც თქვენ მონიშნავთ, და შენახვის შემდეგ ჟურნალს თავიდან კითხულობს, რომ დარწმუნდეს.
